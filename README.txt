MySports HQ — PWA update (version 1.8.0)

Upload these files to the root of the realNarwhal GitHub Pages repository, replacing the files with the same names:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

The new app name is MySports HQ and both icons use the supplied logo. After GitHub Pages publishes, open https://realnarwhal.github.io/ in Chrome and refresh. If the old app is already installed, remove it from the phone home screen, clear the site's data in Chrome, reopen the page, then install it again so Android picks up the new name and icon.

Live scores still require internet and refresh only while the page is open.
